# Engineers Factory — Foundry Application Site

React + Vite + Tailwind site with the Foundry application form.

## Push to GitHub

```bash
git init
git add .
git commit -m "Initial commit: Foundry application site"
git branch -M main
git remote add origin https://github.com/<your-username>/<your-repo>.git
git push -u origin main
```

## Deploy on EC2

See `setup-react-nginx.sh` in this repo (or the outputs folder) for the
one-shot install + build + Nginx serve script.
